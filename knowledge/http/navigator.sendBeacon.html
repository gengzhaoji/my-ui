navigator.sendBeacon()：页面卸载时可靠发送数据的解决方案 #

navigator.sendBeacon() 是专为解决页面卸载时数据发送难题而设计的Web API，它能在用户离开页面时可靠地发送少量数据到服务器，是分析、监控等场景的理想选择。

🌟 核心优势 #

1. 卸载页面时的可靠性 #

  • 核心价值：浏览器保证在页面卸载过程中发出的请求尽可能被发送
  • 对比传统方法：
    • 同步XHR：阻塞页面卸载，导致用户体验卡顿
    • 异步XHR/fetch：请求可能被取消，数据丢失
    • sendBeacon：专门优化卸载场景，数据发送成功率最高

2. 异步且不阻塞 #

  • 发送过程完全异步，不阻塞主线程、页面交互或后续页面加载
  • 用户完全感知不到数据发送过程

3. 简单易用的API #

// 基础用法
const success = navigator.sendBeacon(url, data);

// 支持多种数据类型
navigator.sendBeacon(url, "simple string"); // 文本
navigator.sendBeacon(url, new Blob([JSON.stringify(data)])); // JSON
navigator.sendBeacon(url, new FormData(form)); // 表单数据

4. 浏览器优化 #

  • 低优先级调度，减少对用户体验的影响
  • 可能合并多个请求，优化网络使用

5. 无需处理响应 #

  • 设计为"发后即忘"模式，简化客户端代码
  • 服务器端负责处理数据接收的可靠性

🚀 主要使用场景 #

1. 用户行为分析 #

// 记录页面停留时间
window.addEventListener('unload', () => {
  const duration = Date.now() - performance.timing.navigationStart;
  const data = { event: 'pageview', duration };
  sendAnalytics(data);
});

function sendAnalytics(data) {
  const blob = new Blob([JSON.stringify(data)], 
    { type: 'application/json' });
  navigator.sendBeacon('/analytics', blob);
}

2. 错误和性能监控 #

// 全局错误监控
window.addEventListener('error', (event) => {
  const errorData = {
    message: event.message,
    filename: event.filename,
    lineno: event.lineno,
    colno: event.colno,
    stack: event.error?.stack
  };
  
  const blob = new Blob([JSON.stringify(errorData)], 
    { type: 'application/json' });
  navigator.sendBeacon('/error-log', blob);
});

3. 表单自动保存 #

// 表单离开时保存草稿
const form = document.getElementById('registration-form');

window.addEventListener('beforeunload', () => {
  if (formHasChanges(form)) {
    navigator.sendBeacon('/save-draft', new FormData(form));
  }
});

4. 其他应用场景 #

  • 游戏状态保存
  • 广告点击跟踪
  • A/B测试数据收集
  • 页面性能指标上报

⚠️ 重要限制与注意事项 #

1. 数据大小限制 #

  • 各浏览器实现不同，通常限制在 64KB左右

  • 最佳实践：

    const data = JSON.stringify(largeData);

if (data.length > 60000) {
  // 智能缩减数据大小
  sendCriticalDataOnly();
} else {
  const blob = new Blob([data], {type: 'application/json'});
  navigator.sendBeacon('/endpoint', blob);
}

2. 请求头限制 #

  • 无法自定义请求头（如Authorization）

  • Content-Type自动设置：

    数据类型Content-Type
    Stringtext/plain;charset=UTF-8
    BlobBlob的type属性
    FormDatamultipart/form-data
    URLSearchParamsapplication/x-www-form-urlencoded

3. 其他限制 #

  • 仅支持POST方法

  • 无法获取响应：设计为单向发送

  • 浏览器兼容性：

    // 兼容性检查与降级方案
if (navigator.sendBeacon) {
  // 使用sendBeacon
} else {
  // 降级方案：同步XHR（阻塞卸载）
  const xhr = new XMLHttpRequest();
  xhr.open('POST', url, false); // 同步请求
  xhr.send(data);
}

🛠️ 使用示例与最佳实践 #

完整实现示例 #

// 页面分析工具
const pageAnalytics = {
  startTime: Date.now(),
  
  init() {
    // 页面加载时记录起始时间
    window.addEventListener('load', () => {
      this.startTime = Date.now();
    });
    
    // 页面卸载时发送数据
    window.addEventListener('unload', () => {
      this.sendUnloadData();
    });
  },
  
  sendUnloadData() {
    const data = {
      event: 'page_unload',
      path: window.location.pathname,
      duration: Date.now() - this.startTime,
      referrer: document.referrer,
      screen: `${screen.width}x${screen.height}`
    };
    
    try {
      const jsonData = JSON.stringify(data);
      const blob = new Blob([jsonData], {
        type: 'application/json; charset=UTF-8'
      });
      
      const url = 'https://api.example.com/analytics';
      const success = navigator.sendBeacon(url, blob);
      
      if (!success) {
        console.warn('Beacon failed, using fallback');
        this.saveToLocalStorage(data); // 本地存储下次发送
      }
    } catch (e) {
      console.error('Analytics send error:', e);
    }
  },
  
  saveToLocalStorage(data) {
    // 存储数据以便下次发送
    const pending = JSON.parse(localStorage.getItem('pendingAnalytics') || '[]');
    pending.push(data);
    localStorage.setItem('pendingAnalytics', JSON.stringify(pending));
  }
};

// 初始化分析
pageAnalytics.init();

最佳实践建议 #

  1. 只发送必要数据：严格遵守大小限制

  2. 使用Blob设置正确Content-Type：确保服务器正确解析

  3. 处理发送失败情况：本地存储+下次发送

  4. 结合visibilitychange事件：处理页面隐藏场景

    document.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'hidden') {
    navigator.sendBeacon('/visibility-change', data);
  }
});

  5. 服务器端处理重复数据：可能因重试机制导致重复发送

总结 #

navigator.sendBeacon() 是解决页面卸载时数据发送这一特定问题的完美工具，特别适用于：

  • 用户行为分析
  • 错误监控和日志记录
  • 表单自动保存
  • 关键指标上报

通过其可靠性和易用性，sendBeacon 已经成为现代Web应用中不可或缺的工具，帮助开发者在用户离开页面时不丢失任何关键数据。
